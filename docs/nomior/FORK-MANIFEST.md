# Fork manifest — upstream files Nomior Code modifies

Every touch of an upstream file is listed here (path + why). CI flags a sync
when one of these files changed upstream. Everything else Nomior adds lives in
new files (`apps/web/src/nomior/**`, `apps/server/src/nomior/**`,
`packages/nomior-*`, `apps/nomior-landing`, `scripts/nomior/**`) and needs no
entry.

| Upstream file                                       | Why we touch it                                                                              |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `apps/web/src/components/sidebar/SidebarChrome.tsx` | Sidebar utility item + footer-page detection for the `/nomior` panels.                       |
| `apps/web/src/routeTree.gen.ts`                     | Generated by TanStack Router; regenerated after adding the `/nomior` route files (additive). |
| `package.json` (root)                               | `dev:landing` / `build:landing` scripts for `apps/nomior-landing`.                           |
